# Voice Commands Quick Reference

## 🎤 How to Use Voice Commands

### Step 1: Tap the Microphone Icon
- Look for the 🎤 icon in the top-right corner
- Icon turns **RED** when listening

### Step 2: Speak Clearly
Wait for: *"Listening. Please say your start and destination room."*

### Step 3: Say Your Command

## 📝 Command Examples

### Floor Navigation (Indoor Maps)
```
✅ "From Room 101 to Room 205"
✅ "Navigate from Computer Lab to Library"
✅ "Room 101 to Room 205"
✅ "Start at Cafeteria destination Dean's Office"
✅ "Computer Lab to Library"
```

### Campus Navigation (Site Plan)
```
✅ "From Main Building to NGO Building"
✅ "Main Building to PAGCOR Building"
✅ "Navigate from NGO to PAGCOR"
✅ "Start at Main Building end at NGO Building"
```

## ✨ What the Voice Assistant Says

### Success
*"Navigation set from [start] to [destination]. Starting navigation."*
- Route appears automatically
- Turn-by-turn guidance begins

### Unclear Speech
*"Oops! Your voice is unclear. Please repeat and say your start and destination room clearly."*
- Try speaking more slowly
- Enunciate room names clearly
- Reduce background noise

### Error
*"Sorry, I could not understand. Please try again."*
- Check microphone permissions
- Ensure quiet environment
- Speak closer to microphone

## 🎯 Tips for Best Results

1. **Speak in Quiet Environment** 🔇
   - Minimize background noise
   - Turn off music/TV

2. **Use Full Names** 📛
   - Say "Room 101" not "101"
   - Say "Computer Lab" not "Computer"

3. **Speak Clearly** 🗣️
   - Don't rush
   - Enunciate each word
   - Speak at normal volume

4. **Natural Language** 💬
   - You can say it different ways
   - System understands variations
   - "From X to Y" or "X to Y" both work

5. **Wait for Confirmation** ⏱️
   - Don't tap anything while listening
   - Wait for voice response
   - Route appears automatically

## 🔴 Listening Indicator

| Icon | Status |
|------|--------|
| 🎤 (normal color) | Ready to listen |
| 🎤 (RED) | Actively listening |
| 🎤 (normal) | Processing speech |

## ❓ Troubleshooting

### "Speech recognition not available"
- Ensure microphone permissions granted
- Check device settings
- Try physical device (not emulator)

### Voice command doesn't trigger
- Tap microphone icon once
- Wait for "Listening..." message
- Grant permissions if prompted

### Wrong rooms selected
- Speak full room name
- Pronounce clearly
- Try again with exact name

## 📱 Device Requirements

- ✅ Android 5.0 or higher
- ✅ Microphone access
- ✅ Internet connection (for cloud speech recognition)
- ✅ Permissions granted

## 🚀 Quick Start

1. Open floor map or campus map
2. Tap 🎤 microphone icon
3. Wait for "Listening..."
4. Say: "From [start] to [destination]"
5. Navigation starts automatically!

---

**Pro Tip**: You can use voice commands even while navigating to change your destination on the fly!
